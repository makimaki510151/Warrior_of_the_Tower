# 塔の戦士

100層の塔を、自動戦闘で登るブラウザゲームです。

## 遊び方

- 約50種の技から、毎回ランダムに5つ提示されます。1つだけ選んで獲得／強化します。
- そのあと、能力確認と戦闘手順の設定を行い、階層に挑みます。
- 手順は上から判定され、条件に合う技がなければ通常攻撃です。
- 敵の詳細情報は表示しませんが、各階層に出る敵は固定です。
- 同じ技を重ねても伸びは一定で、完全な上位互換はありません。
- 敗北時は手順の組み直し、または諦め（最高記録は残る）を選べます。

進行はブラウザに保存されます。

## 公開

ビルド不要です。`index.html` を開くか、GitHub Pages でリポジトリのルートを公開してください。
