# 真・塔の戦士

100層の塔を、自動戦闘で登るブラウザゲームです。

## 遊び方

- 多数の技から、毎回ランダムに5つ提示されます。1つだけ選んで獲得／強化します。
- そのあと、能力確認と戦闘手順の設定を行い、階層に挑みます。
- 手順は上から判定され、条件に合う技がなければ通常攻撃です。
- 敵の詳細情報は表示しませんが、各階層に出る敵は固定です。
- 同じ技を重ねると効果とステータスが伸びます（2枚目以降はステータスに追加ボーナス）。
- 敗北時は手順の組み直し、または諦め（最高記録は残る）を選べます。
- ゲーム内の「更新履歴」にパッチノートがあります。数値調整や仕様変更はそこに追記します。

進行はブラウザに保存されます。

## 公開

ビルド不要です。`index.html` を開くか、GitHub Pages でリポジトリのルートを公開してください。

## パッチノートの更新

`js/patchnotes.js` の先頭に新しい版を追加してください。スキルの base/step、gain、クールダウンなど、できるだけ細かく書いてください。
