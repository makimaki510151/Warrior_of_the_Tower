# 塔の戦士

100層の塔を、自動戦闘で登るブラウザゲームです。戦う前に技を習得し、使う順番と条件をフローチャートのように組みます。

## 遊び方

- 目標は第100層の突破です。
- 戦闘は自動で進みます。プレイヤーが操作するのは、階層に挑む前の技の習得と手順だけです。
- 手順は上から判定されます。条件に合い、再使用できる最初の技を使います。どれも当たらなければ通常攻撃です。
- 技は25種類あります。同じ技は何度でも強化でき、1回ごとの伸びは一定です。2回習得しても威力は倍になりません。どの技も、常に上位というわけではありません。
- 標準表示は体力・攻撃力・防御力です。詳細表示では、現在体力、自動回復の速度と量、回復効率、攻撃と防御の補助効率などが見られます。
- 一度負けると、手順を組み直して同じ階層に再挑戦するか、諦めて1層からやり直すかを選べます。

進行はブラウザに保存されます。

## ローカルで開く

ビルドは不要です。`index.html` をブラウザで開くか、このフォルダで静的サーバを立てます。

```bash
python -m http.server 8000
```

## GitHub Pages

1. このリポジトリを GitHub に置きます。
2. Settings → Pages を開きます。
3. Branch を `main`（または公開したいブランチ）、Folder を `/ (root)` にします。
4. 保存すると、`https://<user>.github.io/<repository>/` で公開されます。

パスは相対参照なので、プロジェクトサイトのサブディレクトリでもそのまま動きます。
